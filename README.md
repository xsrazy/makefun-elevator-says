The funniest thing an elevator would say if it could talk, in the elevator's own weary voice.

## Run it

```sh
python3 main.py
```

Running the program writes the entry line to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).

## Entry

`entry.txt` contains exactly one line, with no trailing newline:

> You pressed every button. Congratulations, we're now stopping at all twelve floors of your regret.
